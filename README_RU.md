# 17TESS VOCAL SAUCE — пересборка на JUCE 8 / VST3 (исходный проект)

## Зачем это нужно

Первая отправленная `.dll` **не была VST2**, а первая `.vst3` была экспериментальной DLL, просто переименованной в `.vst3`. Cubase не принял сборку. Ранее переданные бинарные файлы удалите из VST-папок. Эти исходники — новая реализация на JUCE с официальной VST3-обвязкой. **Это не проверенный в Cubase бинарник:** компиляцию Windows нужно выполнить на Windows, затем проверить в Cubase.

## Что в проекте

- Обработка вокала: Saturation, Distortion с HP и LP, AIR, PUNCH, WET, De-ess, Color EQ, Chorus.
- Трёхполосный EQ с перетаскиваемыми точками и тремя ручками LOW / MID / HIGH. Внимание: EQ — музыкальный широкополосный тон-шейпинг, не точная копия FabFilter.
- Минималистичный Minecraft-inspired пиксельный GUI. Все графические элементы рисуются в JUCE без использования официальных текстур Minecraft.
- Кнопка `+` возле каждого эффекта открывает только его параметры; `+` рядом с EQ открывает частоты точек. Параметры со значениями видны только после открытия панели.
- `SAVE PRESET` / `LOAD PRESET` работают с `.17tesspreset`, без заводских пресетов. При возможности сохраняет в `Presets` внутри VST3-папки, иначе `%APPDATA%\17TESS\VocalSauce\Presets`.
- Состояние плагина сохраняется внутри проекта Cubase через APVTS.

## Собрать на Windows 10/11 x64

1. Установить **Visual Studio 2022 Community** с пакетом **Desktop development with C++** (включая MSVC и Windows SDK).
2. Установить **CMake 3.22+** и **Git** и перезапустить терминал, чтобы команды были в `PATH`.
3. Распаковать ZIP и запустить `BUILD_WINDOWS.bat`.
4. Первый запуск скачает исходники JUCE 8.0.7 с GitHub (нужен интернет); затем скомпилирует x64 VST3.
5. Найти результат (обычно `build\VocalSauce_artefacts\Release\VST3\17TESS VOCAL SAUCE.vst3`). **Это папка** `.vst3`, а не переименованный DLL-файл.
6. Копировать **всю папку** `17TESS VOCAL SAUCE.vst3` в `%COMMONPROGRAMFILES%\VST3\`, убрать старую `17TESS_VOCAL_SAUCE.vst3`, перезапустить Cubase.
7. Открыть **Studio → VST Plug-in Manager**, найти `17TESS VOCAL SAUCE` и вставить его в FX insert.

**Не нужно копировать отдельную DLL в папку VST2.** VST3 должен грузиться через VST3 bundle. При проблемах посмотри вывод сборки и VST Plug-in Manager: сообщение об ошибке лучше прислать дословно.

## Ограничения

- Не проверялось запуском в реальном Windows/Cubase; после локальной сборки нужно проверить совместимость.
- Дисторшн пока без oversampling; на сильном drive возможно aliasing.
- De-esser, transient enhancement и EQ упрощённые DSP-версии, не клоны платных алгоритмов.
- Нет встроенных заводских пресетов (по просьбе 17tess). Пользовательские пресеты XML в `.17tesspreset`.
- На системах с жёсткими правами Windows сохранение рядом с файлом плагина может быть запрещено — предусмотрена пользовательская папка `%APPDATA%`.

## Открытые исходники и лицензирование

Проект использует JUCE; проверь условия лицензирования JUCE перед публикацией или продажей. Исходники JUCE и лицензии не вложены в ZIP: `FetchContent` скачивает JUCE при сборке.

## Тест DSP без JUCE (Linux, macOS)

`c++ -std=c++17 -O2 tests/dsp_test.cpp -o dsp_test && ./dsp_test`

Этот тест проверяет только DSP (не интеграцию в VST3 / Cubase).

## Собрать без Visual Studio на своём компьютере (через GitHub Actions)

1. Создать новый GitHub репозиторий и загрузить **всё содержимое** этой папки (включая `.github/workflows/build-win64.yml`) в корень репозитория.
2. Во вкладке `Actions` открыть `Build 17TESS Vocal Sauce Win64 VST3` и нажать `Run workflow` (или дождаться запуска при push на `main`).
3. Дождаться успешного завершения workflow на Windows и скачать **artifact** `17TESS-Vocal-Sauce-Win64-VST3`.
4. Распаковать zip и найти папку `17TESS VOCAL SAUCE.vst3`. Поместить всю папку в `%COMMONPROGRAMFILES%\VST3\`, а старую несовместимую DLL удалить из папки VST2.

Если GitHub Actions выдаст ошибку, пришли журнал этапа `Configure` или `Compile Release VST3`: по нему можно исправить проект. GitHub Actions не создаёт гарантии работоспособности в Cubase — после сборки нужен скан VST3 и проверка открытия интерфейса.
